# Настройка Telegram-бота

## Команды

Бот регистрирует команды через Bot API при запуске:

```text
start - Начать подбор SPF-средства
help - Помощь и список возможностей
```

`/settings` не добавляется, пока у бота нет пользовательских настроек.

## BotFather

Для production-бота откройте `@BotFather` → `/mybots` → выберите бота и
заполните:

1. **Name**

   ```text
   Sanctum Clinic — подбор SPF
   ```

2. **About**

   ```text
   Персональный подбор SPF-средств по типу и особенностям кожи.
   ```

3. **Description**

   ```text
   Пройдите короткий тест и получите персональную рекомендацию SPF-средства, альтернативы и профессиональный вариант. Рекомендации носят информационный характер и не заменяют консультацию врача.
   ```

4. **Botpic** — квадратный логотип в хорошем качестве.
5. **Commands** — команды выше можно продублировать через `/setcommands`.
   Приложение также обновляет их автоматически при старте.
6. **Main Mini App** — укажите production HTTPS URL Mini App, добавьте
   название, иконку, цвет загрузочного экрана и демонстрационные материалы.
7. **Menu Button**:
   - оставьте меню команд, если `/help` должен быть всегда виден;
   - либо назначьте кнопку открытия Mini App, если это основной сценарий.
8. Отключите добавление в группы и inline mode, если эти сценарии не
   поддерживаются приложением.

Для тестового бота повторите настройку с тестовым HTTPS URL и визуально
отличающимся именем, например `Sanctum Clinic Test`.

## Перед публичным запуском

- Добавить страницу политики конфиденциальности.
- Добавить ссылку на неё в Mini App и справку бота.
- Описать, какие Telegram-данные и ответы теста сохраняются.
- Добавить способ запросить удаление пользовательских данных.
- Проверить `/start`, `/help`, кнопку Mini App и все поддерживаемые сценарии
  на production URL.
- Никогда не хранить `BOT_TOKEN` в Git.
